# Customer & Sales Data Analysis Using SQL

## Project Overview

This project analyzes customer and sales data using SQL and MySQL.

The analysis focuses on sales performance, customer behavior, products, categories, cities, and monthly revenue.

## Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- GitHub

## Dataset

The dataset contains 20 customer sales records with the following fields:

- Customer ID
- Customer Name
- City
- Product
- Category
- Quantity
- Price
- Order Date

## SQL Analysis Performed

### Basic Analysis
- Retrieved customer and product information
- Filtered data using `WHERE`
- Sorted products by price

### Sales Analysis
- Calculated total sales by product
- Calculated sales by city
- Calculated sales by category
- Calculated sales by customer
- Calculated total revenue
- Calculated total orders
- Calculated average product price
- Identified minimum and maximum prices

### Advanced Analysis
- Used `GROUP BY`
- Used `HAVING`
- Used `ORDER BY`
- Used `LIMIT`
- Performed monthly sales analysis
- Identified top-selling products
- Identified top customers
- Identified high-value customers

### JOIN Analysis
Created a second customer details table and used `INNER JOIN` to combine customer information with sales data.

## Key Business Insights

- Electronics generated higher sales than Fashion.
- Laptop sales contributed significantly to total revenue.
- Sales were analyzed across Hyderabad, Chennai, Bangalore, Delhi, and Mumbai.
- High-value customers were identified based on total purchase value.
- Monthly sales trends were calculated for January, February, and March 2025.
